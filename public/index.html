Bookstore API

Este sitio publica solo las funciones de Netlify. El frontend se sirve aparte.

Cola: bookstore. Variables: CLOUDAMQP_URL, DATABASE_URL y FUNCTIONS_BASE_URL.

Lectura

  • GET /.netlify/functions/books
  • GET /.netlify/functions/authors
  • GET /.netlify/functions/publishers

Encolar

  • PUT /.netlify/functions/bookUpdate/:id
  • POST /.netlify/functions/bookInsert
  • DELETE /.netlify/functions/bookDelete/:id
  • PUT /.netlify/functions/authorUpdate/:id
  • POST /.netlify/functions/authorInsert
  • DELETE /.netlify/functions/authorDelete/:id
  • PUT /.netlify/functions/publisherUpdate/:id
  • POST /.netlify/functions/publisherInsert
  • DELETE /.netlify/functions/publisherDelete/:id

Procesar la cola

  • GET /.netlify/functions/bookTasks
  • GET /.netlify/functions/authorTasks
  • GET /.netlify/functions/publisherTasks
